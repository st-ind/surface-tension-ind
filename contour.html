Аукцион периода, разложенный на 4 слоя

Contour превращает каждый закрытый 30-минутный период в одно из 6 чтений аукциона — по экстремумам против предыдущего периода, Rotation Factor и проценту перекрытия диапазонов. Это чтение управляет тонировкой бокса, уровнем инвалидации и фильтром сигнала Δ+FVG — без ручной разметки.

Архитектура 4 слоя · L1 → L4

От закрытия периода до сигнала входа — один проход, без отдельных индикаторов поверх.

Layer 1

Период → метрики

На закрытии 30-минутного периода: OTF-экстремумы против N−1, Rotation Factor (−2…+2), процент перекрытия диапазонов, сдвиг POC (hl2/close-прокси) и хвосты на новом сессионном экстремуме.

Layer 2

6-стейт машина

Классификация сверху вниз по первому совпавшему правилу: Strong Trend → Pullback → Fading → Reversal → Sweep → Balance. Reversal подтверждается только следующим периодом — иначе демоутится в Sweep.

Layer 3

Статус-таблица + plot-серии

Опциональная таблица State / Direction / Reason в углу графика. Отдельно всегда считаются 4 серии для своих стратегий: состояние, разрешённое направление, уровень инвалидации, накопленный RF дня.

Layer 4

Δ+FVG сигнал

Дельта-бар + Fair Value Gap, отфильтрованные по чтению периода — с аддитивными байпасами VWAP / EQ / Volatile Bar / уровней и прозрачными тегами прямо на бейдже сигнала.

Состояния 6 чтений аукциона · + 1 без чтения

Каждый закрытый период проверяется сверху вниз по шести правилам — побеждает первое совпавшее. Strong Trend подтверждается сразу; остальные пять — только после того, как период N+1 не опроверг чтение.

Strong Trend 1

Сильный тренд. OTF-стрик ≥2, |RF|=2, экстеншн держится, откат <50%.

"OTF×3 RF+2 ext held"
Pullback 2

Откат. Тело держится в зоне Single Print, откат 30–60% без пробоя.

"pullback 42% SP hold"
Fading 3

Угасание. 2+ из 5 признаков истощения: decay, растущий overlap, хвост, POC не следует, RF упал.

"fade vote 3/5"
Reversal 4

Разворот. Закрытие пробивает старый экстремум ПОСЛЕ угасания — подтверждённая смена стороны.

"OTF break after fade, RF+1"
Sweep 5

Вынос. Пробой без предварительного угасания — либо фитиль проколол уровень и закрылся обратно.

"wick pierce, closed back"
Balance 6

Баланс. Два периода подряд перекрываются ≥70% диапазона, |RF|≤1 — преимущества ни у кого.

"overlap 78% ×2"
Undefined 0

Ни одно из шести правил не подошло. Период остаётся без чтения: без разрешённого направления и без уровня инвалидации.

Reversal — единственное чтение, которое умеет себя переобувать: если период N+1 закрывается обратно за уровень пробоя, чтение задним числом становится Sweep. Не подтвердился разворот — не подтвердился, без исключений.

Анатомия бейджа

Стрелка — направление дельта-бара с подтверждённым FVG. Дальше через точку клеятся теги пройденных байпасов: ↑·F, ↓·Eq, ↑·V·PD. Один сигнал может нести сразу несколько тегов — видно каждую причину, по которой он прошёл фильтр.

br → BR ✓ → BR ▲

Эволюция CHoCH-лейбла

Пробой против прошлого пробоя даёт «br». Закрытие ТЕЛОМ за уровень — апгрейд на «BR ✓». Если после этого раньше приходит BOS в ту же новую сторону — «BR ▲»/«BR ▼», подтверждённая смена тренда. Live-демо: br

оранжевый ◆

Подсветка окна BR ✓

При теловом сломе CHoCH все уже отображённые сигналы того же направления в окне «пробитая вершина − N баров → бар пробоя» перекрашиваются в оранжевый — задним числом видно, какие ◆ вели к этому слому.

▲ / ▼

Тест FVG

Первое касание зоны Fair Value Gap после её формирования отмечается треугольником по направлению — без градации «сильный/слабый», просто факт первого теста.
